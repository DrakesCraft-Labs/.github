## ⚙️ Principios de Desarrollo

- 🛡️ **Cero Reset de Servidor**: Toda migración a Rust lee y escribe de forma transparente sobre la base de datos SQLite `stored-blocks.db` nativa de Slimefun4.
- ⚡ **Grafo de Energía y Tickers en Rust**: Procesamiento multi-hilo nativo a velocidad C (nanosegundos) eliminando pausas de Garbage Collector (GC).
- 🔗 **Java 21 Project Panama (FFM API)**: Comunicación nativa C-ABI de ultra baja latencia entre Purpur 1.21.11 y bibliotecas dinámicas `.dll` / `.so`.
